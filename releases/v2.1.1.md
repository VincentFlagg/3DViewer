**3D Viewer 2.1.1** fixes unpacking archives whose name ends in a dot.

## Fixed

- Unpacking an archive such as `Iron Giant..7z` (a dot before the extension) on a network share failed with *ENOTDIR: not a directory*: the new folder was named `Iron Giant.`, and Windows and SMB shares cannot store names that end in a dot or a space. Folder and file names made by 3D Viewer (unpacking, uploads, new folders, renames) no longer end in a dot or a space, so the folder is now called `Iron Giant`.

If an earlier attempt left an empty `Iron Giant` folder next to the archive, delete it and click **Unpack** again.

## Update

Pull the new image and redeploy (or `docker compose pull && docker compose up -d`), then hard-refresh your browser.

Image: `ghcr.io/vincentflagg/3dviewer:2.1.1` (or `:2.1`, `:latest`), for amd64 and arm64.

**3D Viewer 3.0.1** makes the search look inside sub-folders.

## Changed

- **Search** now covers the open folder and all its sub-folders. At the top level it searches the whole library.
- **What it matches:** file names, folder names, display names, descriptions, series names and your own tags (when signed in). Every word you type must match.
- **Results:** one list, matching folders first, each model showing the folder it is in.
- **Using the results:** a click opens the model or folder. Esc, the × in the search box, or clearing the box goes back to the folder.

## Update

Pull the new image and redeploy (or `docker compose pull && docker compose up -d`), then hard-refresh your browser (Ctrl+Shift+R, or Cmd+Shift+R on a Mac).

Image: `ghcr.io/vincentflagg/3dviewer:3.0.1` (or `:3.0`, `:latest`), for amd64 and arm64.

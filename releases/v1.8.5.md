**3D Viewer 1.8.5** shows Blender files in 3D.

## New

- **Blender files (.blend) in 3D.** A `.blend` is now a model like any other: it gets a rendered thumbnail and opens in the viewer (rotate, zoom, sun lamp, saved view…). 3D Viewer reads what is stored in the file itself, without Blender:
  - the mesh objects of the scene, placed where they are, from Blender 2.8 to 4.x, also compressed files;
  - their material colour, or the base colour texture when it is packed in the file (with the UV map);
  - copies made by **particle systems** (trees, grass, rocks) and by **instanced collections**. Particles that Blender places when it opens the file are spread over the emitter here in the same number and size, but not at the same spots;
  - a **colour ramp** in a material (for example leaves by season) gives each copy its own colour.
- Not shown: modifiers and geometry nodes (the mesh is shown as modelled), textures that are not packed in the file, curves, text and metaballs. A file without any mesh shows the preview picture Blender saved in it.
- Blender files are shown Z-up (Blender's axes), one Blender unit as one millimetre.

## Changed

- Blender files are no longer listed with the ZBrush and 123D Catch files; the Admin switch is back to **Show ZBrush and 123D Catch files**.

## Update

Pull the new image and redeploy (or `docker compose pull && docker compose up -d`), then hard-refresh your browser. Your libraries, settings, notes and thumbnails are kept. Thumbnails of `.blend` files are made in the background after the update.

Image: `ghcr.io/vincentflagg/3dviewer:1.8.5` (or `:latest`), for amd64 and arm64.

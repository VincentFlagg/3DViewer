**3D Viewer 1.8.0** lists Blender files with their preview picture.

## New

- **Blender files (.blend)** now appear in the gallery:
  - the card shows the preview picture Blender saves inside the file (the one you see in Blender's file browser), also for compressed files; a file saved without one shows a Blender icon;
  - click to download it, or select, move and delete it like a model;
  - there is no 3D view: a `.blend` is Blender's own working file, which only Blender can open. For a 3D view, export the model from Blender as GLB, STL or OBJ and keep it next to the `.blend`.
- The Admin switch is now **Admin → Viewer defaults → Show ZBrush, 123D Catch and Blender files** (on by default).

## Update

Pull the new image and redeploy (or `docker compose pull && docker compose up -d`), then hard-refresh your browser. Your libraries, settings, notes and thumbnails are kept.

Image: `ghcr.io/vincentflagg/3dviewer:1.8.0` (or `:latest`), for amd64 and arm64.

**3D Viewer 4.0.1** gives the Admin page a cleaner layout.

## Changed

- **Admin page in tabs**: instead of one long page, the settings are grouped by subject, one group at a time:
  - **Library**: libraries, network shares, trash, duplicates, import from link
  - **Accounts**: accounts and private server, single sign-on, two-factor sign-in, access and the admin password, API tokens, share links
  - **Printing**: printers and print cost
  - **Viewer**: viewer defaults and the app icon
  - **Thumbnails**: thumbnails and previews, storage, size limits
  - **Notifications**, **Backup**, and **Support & ideas**
- On a phone the tabs are a scrolling row at the top. `/admin#accounts` (or any tab) opens it directly, and the ↑ ↓ ← → keys move between tabs.
- Tidier forms: all fields look alike and fit narrow screens.

## Security

- Updated three libraries (body-parser, multer, zod) to fix denial-of-service issues: specially made requests could tie up the server.

## Update

Pull the new image and redeploy (or `docker compose pull && docker compose up -d`), then hard-refresh your browser (Ctrl+Shift+R, or Cmd+Shift+R on a Mac).

Image: `ghcr.io/vincentflagg/3dviewer:4.0.1` (or `:4.0`, `:latest`), for amd64 and arm64.

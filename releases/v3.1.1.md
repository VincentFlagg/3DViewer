**3D Viewer 3.1.1** makes it easy to send ideas and bug reports.

## New

- **Ideas and bug reports** on the Admin page: links to the public GitHub page to:
  - suggest an idea or vote for one (**Ideas**);
  - open a feature request;
  - report a bug, with a form that asks for the version, NAS and browser.

## Update

Pull the new image and redeploy (or `docker compose pull && docker compose up -d`), then hard-refresh your browser (Ctrl+Shift+R, or Cmd+Shift+R on a Mac).

Image: `ghcr.io/vincentflagg/3dviewer:3.1.1` (or `:3.1`, `:latest`), for amd64 and arm64.

**3D Viewer 1.5.0** unpacks zips that are already in your libraries, lets you select folders, and lists 123D Catch projects.

## New

- **Unpack zips already in a library.** Zips copied into a library (over SMB, from a download folder…) used to stay hidden. Now a zip with 3D models inside shows as a card in its folder:
  - click it to download it;
  - **Unpack** (admin) unpacks it like an uploaded zip: into a new folder named after it, next to it, with a single top-level folder inside the zip left out. The zip then goes to the **trash**, so it can be restored;
  - zips without 3D models are left alone and not shown.
- **Admin → Libraries → Unpack zips** does it for every zip with models in a library, sub-folders included, and reports how many were unpacked.
- The unpacked size limit is the one in **Admin → Limits** (8 GB by default), as for uploads.
- **123D Catch projects (.3dp)** are listed like ZBrush files, with a 123D Catch icon: download, move and delete. They can't be shown in 3D: a `.3dp` holds only the photo list and camera positions, while the mesh was kept by 123D Catch, which Autodesk shut down in 2017. The Admin switch is now **Show ZBrush and 123D Catch files**.
- **Select folders.** In select mode folder cards get a tick box too, and **Select all** includes them. With folders selected:
  - **Download** gives one .zip with each folder and everything in it (no size limit; it is streamed);
  - **Move to…** moves them, also to another library;
  - **Delete** moves them to the trash.

## Update

Pull the new image and redeploy (or `docker compose pull && docker compose up -d`), then hard-refresh your browser. Your libraries, settings, notes and thumbnails are kept.

Image: `ghcr.io/vincentflagg/3dviewer:1.5.0` (or `:latest`), for amd64 and arm64.

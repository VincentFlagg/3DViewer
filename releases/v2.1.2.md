**3D Viewer 2.1.2** fixes the release-notes link in Dockhand.

## Fixed

- Dockhand's release-notes icon opened the releases of a private repository. The image now carries Dockhand's `dockhand.changelog.url` label, so the icon opens the [3D Viewer releases](https://github.com/VincentFlagg/3DViewer/releases).

Dockhand reads the link from the container that is running, so it is correct once you are on 2.1.2.

## Update

Pull the new image and redeploy (or `docker compose pull && docker compose up -d`), then hard-refresh your browser.

Image: `ghcr.io/vincentflagg/3dviewer:2.1.2` (or `:2.1`, `:latest`), for amd64 and arm64.

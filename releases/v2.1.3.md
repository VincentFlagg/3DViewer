**3D Viewer 2.1.3** previews a folder picture before it is saved.

## Changed

- **Folder picture** no longer saves the moment you click. Clicking a picture or model thumbnail, or uploading a picture, shows it in the dialog cropped to 4:3, as the folder card will show it. **Use this picture** saves it; **Cancel** (or Esc) goes back to the current picture.

## Update

Pull the new image and redeploy (or `docker compose pull && docker compose up -d`), then hard-refresh your browser.

Image: `ghcr.io/vincentflagg/3dviewer:2.1.3` (or `:2.1`, `:latest`), for amd64 and arm64.
